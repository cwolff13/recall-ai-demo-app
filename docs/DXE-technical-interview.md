# Technical Interview Details

- You'll write a demo application showcasing the Recall API and its functionality.
- The demo app should be written from the perspective of creating an application that Recall customers could extend.
- You'll have 24 hours from when you receive your test account to complete it.
- We'll have a call where you will demo the application and walk through your code.
- During the call, we'll also discuss how you would improve the Recall API and documentation. You do not need to prepare anything in writing; this will be a verbal discussion.

## Deliverable

- A link to the GitHub repository containing the demo application.

## What We're Looking For

You'll be assessed on the quality of your code and written communication.

Specifically:

- The structure of the project, including:
  - Code organisation
  - Repository structure
  - Documentation
- The quality of the demo application. It does not need to be fully polished, but it should be presentable.
- The clarity of the code, comments, and README.
- The relevance of the demo application to Recall's end customers. You do not need to have a perfect understanding of who Recall's customers are, but you should be able to explain why you chose the application you built.
